# Student Directory — StudentPortal

A responsive Student Directory built with **React Components & Props** and **Bootstrap 5**, based on the supplied reference design.

## Features
- Responsive Bootstrap navbar and search field
- Breadcrumb navigation
- Reusable `StudentCard` component using props
- Responsive Bootstrap grid (1 / 2 / 4 cards per row)
- Search by student name, ID, or major
- Add Student modal with form validation
- View Profile modal
- Delete student action
- Pagination
- Dismissible success/info alert
- Footer with navigation and contact information

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually `http://localhost:5173`).

## Create production build
```bash
npm run build
npm run preview
```

## GitHub submission
1. Create a repository named `student-directory` on your GitHub account.
2. Extract this project ZIP and open the folder in VS Code.
3. In the terminal, run:
   ```bash
   git init
   git add .
   git commit -m "Build responsive Student Directory with React and Bootstrap"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/student-directory.git
   git push -u origin main
   ```
   If `origin` already exists, use `git remote set-url origin https://github.com/YOUR-USERNAME/student-directory.git`.
4. Open your repository on GitHub and copy its URL for submission.
5. Run the app in your browser, take a screenshot of the final UI, and include it in your submission.

## Add your teacher as a collaborator
You need repository admin/owner access to invite collaborators. On GitHub:
1. Open your repository.
2. Go to **Settings → Collaborators** (sometimes **Collaborators and teams**).
3. Click **Add people**.
4. Search for your teacher's exact GitHub username: `bismasahr-dev` (verify this is the intended account).
5. Select the account and send the invitation. Your teacher must accept it.
